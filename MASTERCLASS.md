# mgen: что это, как сделано и как это показать

Документ для мастер-класса 24 октября. Первая половина — про инструмент, который участники
унесут с собой. Вторая — про то, как он был собран за один вечер, и это, пожалуй, интереснее
самого инструмента.

Репозиторий: <https://github.com/Killblonde/mgen>

# Часть 1. Что это за инструмент

## Проблема

Человек хочет картинку для поста, обложку для видео или оживить фотографию. Сегодня он идёт
в сервис с подпиской, где непонятно, за что списывают деньги, нет нормальных ссылок на файлы
и всё надо делать руками в браузере. А если он уже работает в Claude Code — ему хочется просто
сказать словами «сделай обложку» и получить файл в папке проекта.

## Решение

`mgen` — одна команда в терминале, которая умеет шесть вещей:

| Команда | Что делает |
|---|---|
| `mgen setup` | один раз сохранить ключ kie.ai |
| `mgen balance` | сколько осталось денег |
| `mgen models` | какие модели есть и сколько стоят |
| `mgen image "описание"` | картинка по описанию, можно по своим фото |
| `mgen edit файл.jpg "что изменить"` | правка готовой картинки |
| `mgen video файл.jpg "что происходит"` | видео из картинки, можно петлёй |
| `mgen status <id>` | забрать результат долгой генерации |
| `mgen frames видео.mp4` | нарезать видео на кадры для анимации при прокрутке |
| `mgen template scroll` | положить в проект готовую анимацию прокрутки |
| `mgen doctor` | проверить, всё ли готово к работе |

Плюс **два навыка для Claude Code**. Первый, `mgen`, избавляет от необходимости помнить
команды: пишешь «сделай три варианта иконки подешевле», и агент сам собирает команду,
дописывает промпт и показывает цену. Второй, `mgen-site`, собирает лендинг по скриншоту
понравившегося сайта: разбирает стиль словами, показывает макет с переключателями шрифтов
и палитр, доводит до готовой страницы с видео при прокрутке. Вся дорога от скриншота
до открытой страницы стоит около 350 кредитов, примерно $1.75.

## Три принципа, на которых всё построено

**Деньги видно заранее.** Перед каждой генерацией на экран выводится модель, количество,
цена в кредитах и долларах, текущий баланс и сколько останется. Без подтверждения ничего
не запускается. Если денег не хватает — отказ происходит до отправки задачи, а не после.

```
Что собираюсь сделать
  модель:    Nano Banana Pro (Google)
  сколько:   1 картинка
  формат:    16:9
  качество:  2K
  референсы: 2 шт.
  цена:      18 кредитов (примерно $0.090)
  баланс:    238 кредитов (примерно $1.19)
  останется: 220 кредитов

Запускаем? [д/н]
```

**Сначала дёшево, потом красиво.** Черновик стоит 4 кредита, финал — 18. Правило «2–4 черновика,
человек выбирает, потом финал» зашито и в документацию, и в навык, чтобы агент не жёг деньги
на первой же попытке.

**Ключ принадлежит человеку.** Никакого общего кошелька и посредников: каждый платит kie.ai
со своего баланса. Ключ хранится в домашней папке с правами 600, при вводе не показывается,
в консоль и логи не попадает, в папку проекта не пишется.

## Что участник делает один раз

```bash
npm i -g https://github.com/Killblonde/mgen.git
```

```bash
mgen setup
```

До этого — аккаунт на kie.ai, пополнение на $5 и ключ со страницы kie.ai/api-key.
Node.js уже стоит у всех, кто пользуется Claude Code, отдельно ставить не нужно.

## Пять сценариев, которые стоит показать

```bash
# 1. Обложка 16:9
mgen image "обложка для видео: ноутбук на столе у окна, утренний свет, тёплые цвета, свободное место слева под заголовок" --size 16:9

# 2. Три дешёвых варианта на выбор
mgen image "иконка приложения: бумажный самолётик, плоский стиль" --draft --n 3

# 3. Портрет по своим фото
mgen image "портрет в деловом стиле, светлый кабинет, мягкий свет от окна, по грудь" --ref я1.jpg --ref я2.jpg --ref я3.jpg --size 4:5

# 4. Оживить фотографию, петлёй для сайта
mgen video portret.jpg "лёгкое движение волос, камера очень медленно приближается" --loop

# 5. Правка готовой картинки
mgen edit cover.jpg "сделай фон темнее, убери лишние предметы со стола"
```

Результат падает в папку `generated/` рядом с JSON-файлом, где записаны промпт, модель,
параметры, цена и номер задачи. Через месяц понятно, как была сделана удачная картинка.

## Сколько это стоит

200 кредитов kie.ai = $1.

| Что | Цена |
|---|---|
| Набросок (`--model sketch`) | 0.8 кредита ≈ $0.004 |
| Черновик (`--draft`) | 4 кредита ≈ $0.02 |
| Качественная картинка | 18 кредитов ≈ $0.09 |
| Качественная в 4K | 24 кредита ≈ $0.12 |
| Правка картинки | 4 кредита ≈ $0.02 |
| Видео 5 секунд, черновик | 19 кредитов ≈ $0.10 |
| Видео 5 секунд, лучшая модель | 140 кредитов ≈ $0.70 |

На $5 — примерно 55 качественных картинок или 250 черновиков. Полная таблица и инструкция,
как её обновлять, — в файле `PRICES.md`. Все цены лежат в одном месте, в `prices.json`:
сервис меняет прайс — правится один файл, пересчёт происходит сам.

# Часть 2. Как это было сделано за один вечер

Это и есть содержание мастер-класса: не «нейросеть написала код», а то, каким должен быть
процесс, чтобы на выходе получился рабочий инструмент, а не красивая демка.

## Шаг 1. Техническое задание одним сообщением

Задача ставилась не словами «сделай CLI для картинок», а списком из девяти пунктов: технологии
и почему именно они, поведение каждой команды, что делать с ключом, как выглядят ошибки,
что проверить и в каком бюджете, что прислать в конце. Два ограничения были заданы жёстко:
**не копировать чужие решения** и **уложить тесты в 400 кредитов**.

Вывод для участников: качество результата задаётся на этом шаге, а не промптом «сделай хорошо».
Чем точнее сказано, что считается готовым, тем меньше переделок.

## Шаг 2. Документация раньше кода

Первое, что было сделано, — чтение официальной документации сервиса: как создаются задачи,
как забирается результат, как грузятся свои файлы, какие лимиты, как выглядят ошибки.
Выяснилось важное: **kie.ai возвращает ошибки с кодом HTTP 200**, а настоящий код лежит внутри
ответа. Если бы код писался «по памяти», программа считала бы ошибки успехом.

Названия моделей и цены тоже взяты из документации и с живой страницы прайса, а не из головы.
Модели за год поменялись: актуальны Nano Banana Pro и Seedance 2.5, а не то, что помнит модель.

Вывод: нейросеть уверенно выдумывает параметры API. Правило «сначала документация, потом код»
экономит часы отладки.

## Шаг 3. Два вопроса — и дальше без согласований

По ходу работы нашлись два решения, которые нельзя принимать за заказчика: видео в хорошем
разрешении стоит 315 кредитов за пять секунд (ставить ли такое по умолчанию — выбрали 480p
за 140), и нужен ли звук по умолчанию (выбрали «нет»). Всё остальное — выбор моделей,
структура файлов, формат имён — решалось без вопросов.

Вывод: спрашивать стоит только там, где от ответа меняется результат. Пятнадцать уточняющих
вопросов подряд — признак того, что агент боится, а не работает.

## Шаг 4. Проверка на живых деньгах

Ничего не считается сделанным, пока не запущено по-настоящему. Проверялось:

- `setup` с неверным ключом — отказ, ничего не сохранилось;
- `setup` с верным — файл с правами 600;
- картинка черновиком, три варианта, качественная картинка с двумя референсами;
- видео с петлёй — получился mp4, 4 секунды, h264;
- правка картинки, статус завершённой задачи;
- ошибки: нет ключа, нет файла, не хватает кредитов, неизвестный флаг, неподдерживаемый
  формат кадра, слишком длинное видео для дешёвой модели;
- установка одной командой в чистой папке и весь сценарий из инструкции с нуля;
- отсутствие ключа в файлах, в истории git, в JSON рядом с картинками и в логах.

Ушло 98 кредитов из разрешённых 400 — примерно 49 центов.

По ходу проверки нашлись две настоящие ошибки, которых не видно «на глаз»:
программа падала, если оборвать вывод (`mgen models | head`), и навык неверно описывал
поведение подтверждения внутри Claude Code.

Вывод: тест на реальных данных находит то, чего не видит ни код-ревью, ни сам агент.
Отдельный бюджет на проверку — не роскошь, а часть задачи.

## Шаг 5. Проверка чужими руками

Навык для Claude Code проверялся не там же, где писался, а в отдельных свежих сессиях:
четыре просьбы обычным человеческим языком — «сделай обложку», «три варианта подешевле»,
«оживи фото петлёй», «поправь картинку». Агент вызывал навык сам и цену называл, но три
формулировки пришлось переписать — например, агент не знал, что внутри Claude Code запуск
без флага `--yes` ничего не тратит, а просто печатает цену.

Вывод: инструкцию для агента проверяют на агенте, который её впервые видит. Как и инструкцию
для человека — на человеке, который не присутствовал при написании.

## Что получилось в цифрах

- 1 вечер работы;
- код без единой внешней зависимости (ffmpeg ставится отдельно и только по согласию);
- 12 автоматических тестов;
- 4 документа: инструкция для новичка, таблица цен, описание архитектуры, навык для агента;
- 98 кредитов (49 центов) на проверку живыми генерациями.

## Что честно сказать участникам про ограничения

- Сходство при генерации по своим фото — хорошее, но не идеальное: это не монтаж.
- Текст на картинках модели пишут с ошибками, заголовки лучше добавлять в редакторе.
- Видео любит спокойное короткое движение; резкие повороты ломают кадр.
- Файлы на стороне сервиса живут 14 дней, поэтому программа скачивает их сразу.
- На Windows код написан с учётом особенностей, но вживую не проверялся — у кого Windows,
  тот первый и проверит.

# Часть 3. Сценарий демонстрации, 12 минут

| Время | Что показываем | Что говорим |
|---|---|---|
| 0:00–2:00 | Установка: `npm i -g …`, `mgen setup`, `mgen balance` | что ключ свой, деньги свои, посредников нет |
| 2:00–4:00 | `mgen models` | 0.8 кредита за набросок, 18 за качество, видео считается за секунду |
| 4:00–7:00 | `mgen image … --draft --n 3`, показываем три файла | правило «сначала черновики, потом финал» |
| 7:00–9:00 | Повторяем лучший промпт без `--draft` | разница в качестве за 9 центов |
| 9:00–11:00 | В Claude Code: «оживи эту картинку, нужна петля для сайта» | агент сам собрал команду и показал цену |
| 11:00–12:00 | Открываем JSON рядом с файлом | промпт, модель и цена сохранены, работу можно повторить |

Запасной вариант на случай плохого интернета: в репозитории лежит папка `examples/` —
картинка-черновик, картинка по двум референсам и видео с петлёй, у каждой рядом JSON
с промптом и ценой. Можно показать их и разобрать вывод программы по шагам.
