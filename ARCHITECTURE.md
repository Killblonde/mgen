# Как устроен mgen (для того, кто будет править код)

Node 18+, модули ES, ноль зависимостей — только встроенный `fetch`, `FormData` и `readline`.

```
bin/mgen.js          запуск, перехват ошибок
src/cli.js           разбор команды, подсказка help
src/args.js          разбор флагов (--ref, --n, --size …)
src/config.js        ключ: KIE_API_KEY важнее ~/.mgen/config.json (права 600)
src/api.js           запросы к kie.ai, повтор при 429 и 5xx
src/upload.js        загрузка локальных файлов в хранилище kie.ai
src/models.js        какие модели есть и как собрать для них input
src/price.js         расчёт цены из prices.json
src/run.js           общий сценарий: план → подтверждение → ожидание → скачивание
src/naming.js        имена файлов (дата + промпт латиницей + номер)
src/download.js      скачивание результата и JSON рядом с ним
src/commands/*.js    по файлу на команду
prices.json          единственное место с ценами (как обновлять — PRICES.md)
skill/SKILL.md       навык для Claude Code
test/unit.test.js    быстрые проверки без обращения к kie.ai: npm test
```

## Что важно знать про API kie.ai

- Все генерации асинхронные: `POST /api/v1/jobs/createTask` возвращает `taskId`,
  результат забирается через `GET /api/v1/jobs/recordInfo?taskId=…`.
- **Ошибки приходят с HTTP 200**, настоящий код лежит в теле (`code`). Поэтому в `api.js`
  проверяется именно `code`: 401 — ключ, 402 — кредиты, 429 — лимит частоты, 422/500 — параметры.
- Лимит: 20 новых задач за 10 секунд на аккаунт. При `--n 3` задачи отправляются с паузой,
  при 429 запрос повторяется с нарастающей паузой (до 5 попыток).
- Свои файлы передаются только ссылкой, поэтому сначала идёт бесплатная загрузка
  на `https://kieai.redpandaai.co/api/file-stream-upload`. Загруженный файл живёт 24 часа.
- Готовые файлы kie.ai хранит 14 дней — `mgen` сразу скачивает их в `./generated/`.
- Петля видео делается штатным параметром Seedance: `last_frame_url` = `first_frame_url`.

## Как добавить модель

1. Найти её страницу в <https://docs.kie.ai> (раздел Market), взять точное имя из поля `model`
   и список полей `input`.
2. Добавить цену в `prices.json` (цена видео — за секунду, картинки — за штуку).
3. Добавить запись в `imageModels` или `videoModels` в `src/models.js` с функцией `build`.
4. `npm test` и `mgen models` — проверить, что цена и описание на месте.

## Как сменить имя команды

Поменять `CLI_NAME` в `src/brand.js` и ключ `bin` в `package.json` — больше нигде имя не зашито.
