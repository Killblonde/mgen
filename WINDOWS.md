# Проверка на Windows

**Большая часть уже проверяется сама.** При каждом изменении кода GitHub Actions гоняет
`mgen` на настоящей Windows (плюс macOS и Linux, на Node 18 и 22): установка одной командой,
подсказки команд, поведение без ключа, установка навыков и файлов правил для других агентов,
шаблон прокрутки, нарезка кадров со скачиванием ffmpeg.exe и сборка сайта в один файл.
Результат виден на вкладке Actions в репозитории.

Что автоматика проверить не может и что стоит пройти руками хотя бы раз:

| Шаг ниже | Кто проверяет |
|---|---|
| 1, 2, 4, 6, 7 | GitHub Actions, при каждом пуше |
| 3 (`mgen setup`: скрытый ввод ключа) | только человек: нужен живой терминал |
| 5 (настоящая генерация картинки) | только человек: нужен ключ и деньги |
| внешний вид в консоли (русские буквы, значки) | только человек, лучше в Windows Terminal |

Полный список ниже, он занимает минут двадцать.

Проверяйте в **Windows Terminal** (в нём нормально видны русские буквы и значки). Если открылась
старая консоль `cmd` и вместо букв «кракозябры», это особенность старой консоли, а не программы.

## 1. Node.js

```powershell
node -v
```

Ожидаем версию 18 или новее. Если команда не найдена, поставьте Node с https://nodejs.org (кнопка LTS).

## 2. Установка одной командой

```powershell
npm i -g https://github.com/Killblonde/mgen.git
mgen --version
```

Ожидаем номер версии. Если PowerShell пишет, что запуск скриптов запрещён, помогает
`npm config get prefix` и запуск `mgen` из этой папки, либо перезапуск терминала.

## 3. Ключ

```powershell
mgen setup
```

Проверяем: открылась ли в браузере страница kie.ai/api-key; **не видно ли ключа при вводе**;
после ввода появился ли файл `%USERPROFILE%\.mgen\config.json`; нет ли ключа в текущей папке.

## 4. Общая проверка

```powershell
mgen doctor
```

Ожидаем: Node, ключ, баланс и папка отмечены галочками, ffmpeg пока со значком «!».
Текст должен читаться по-русски.

## 5. Картинка

```powershell
mgen image "первый экран сайта: ноутбук на столе у окна, утренний свет" --draft --size 16:9
```

Проверяем: показан план с ценой и балансом; на вопрос отвечаем `д`; файл появился в папке
`.\generated`, имя файла латиницей, рядом лежит `.json`.

## 6. Нарезка кадров и ffmpeg

```powershell
mgen frames .\generated\ваше-видео.mp4 --out .\frames --count 120 --width 1280
```

(Видео берите любое, можно сделать его командой `mgen video картинка.jpg "лёгкое движение" --draft`.)

Проверяем: программа сказала, что ffmpeg нет, показала размер загрузки и спросила разрешение;
если кадров в видео меньше, чем попросили, она сама поправила число и объяснила почему;
**права администратора не запрашивались**; файл появился в `%USERPROFILE%\.mgen\bin\ffmpeg.exe`;
кадры нарезались и лежат в `.\frames`.

## 7. Страница с анимацией

```powershell
mgen template scroll --out .\site
```

Скопируйте в `.\site` папку `frames`, возьмите пример разметки из
`templates\scroll\example.html` и откройте страницу в браузере (двойным щелчком).

Проверяем: при прокрутке кадры сменяются плавно; нажмите F12, включите режим телефона
и обновите страницу: вместо анимации должна быть одна картинка.
