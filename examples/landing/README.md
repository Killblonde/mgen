# Учебный лендинг: психолог Анна Ковалёва

Это настоящий результат работы навыка `mgen-site`: от одного скриншота-референса
до страницы с видео в шапке. Никакого ручного дизайна, всё собрано по шагам навыка.

Героиня вымышленная, фотография сгенерирована: это учебный пример, а не чей-то сайт.

## Как посмотреть

```bash
cd examples/landing && python3 -m http.server 8080
```

Откройте `http://localhost:8080` и прокрутите шапку: кадры сменяются по движению колеса.
Потом сузьте окно до ширины телефона и обновите страницу: вместо анимации появится
одна картинка, а текст уедет под неё.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html`, `styles.css` | сама страница, 6 экранов |
| `scroll-frames.js`, `scroll-frames.css` | анимация прокрутки, положены командой `mgen template scroll` |
| `frames/` | 120 кадров шириной 1280, 3.9 МБ, нарезаны командой `mgen frames` |
| `img/anna-start.jpg` | главное фото (Nano Banana Pro), рядом JSON с промптом и ценой |
| `video-istochnik.mp4` | исходное видео, из которого нарезаны кадры (пережато для репозитория) |

## Как повторить у себя

Поставьте навык `mgen-site` (см. README в корне репозитория, раздел 8), пришлите
Claude Code скриншот понравившегося сайта и напишите, для кого лендинг. Дальше навык
проведёт по шагам: разберёт стиль словами, покажет макет с переключателями шрифтов
и палитр, сделает черновики фото, спросит про цену перед каждой тратой и соберёт страницу.

Кадры в этом примере специально облегчены (120 штук по 1280 пикселей, качество 7).
Для своего сайта можно взять тяжелее: `mgen frames видео.mp4 --count 120 --width 1600`.
