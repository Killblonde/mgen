# Примеры: что получается на выходе

Эти файлы сделаны самим `mgen` во время проверки. Рядом с каждым лежит `.json` —
ровно такой же, какой появится у вас в папке `generated/`.

| Файл | Команда | Цена |
|---|---|---|
| `kartinka-chernovik.jpg` | `mgen image "кот-космонавт…" --draft --size 1:1` | 4 кредита ≈ $0.02 |
| `kartinka-pro-s-referensami.jpg` | `mgen image "постер…" --ref 1.jpg --ref 2.jpg --size 16:9` | 18 кредитов ≈ $0.09 |
| `video-petlya.mp4` | `mgen video kartinka.jpg "кот машет лапой…" --draft --duration 4 --loop` | 15.2 кредита ≈ $0.08 |

Ещё в этой папке лежит [landing/](landing/) — целый учебный лендинг, собранный навыком
`mgen-site` по одному скриншоту-референсу: страница, 120 кадров для анимации прокрутки,
фото и исходное видео. Там же написано, сколько он стоил (349 кредитов, около $1.75).

Видео сделано из первой картинки: последний кадр возвращается к первому, поэтому ролик
можно зациклить на сайте.
