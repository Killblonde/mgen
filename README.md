# mgen — анимированные лендинги через kie.ai

[![Проверка](https://github.com/Killblonde/mgen/actions/workflows/proverka.yml/badge.svg)](https://github.com/Killblonde/mgen/actions/workflows/proverka.yml)

`mgen` — мост между сервисом [kie.ai](https://kie.ai) и вашим агентом (Claude Code, Codex,
Cursor). Он даёт агенту всё, из чего собирается дорогой сайт: фотографии, видео,
кадры для анимации при прокрутке и сборку готовой страницы в один файл.

Результат, ради которого всё затевалось: **лендинг, где при прокрутке идёт кино** —
шапка на весь экран, камера едет из точки А в точку Б, текст поверх читается, на телефоне
вместо анимации аккуратная статика. Такие страницы делают студии за недели; здесь это
маршрут из нескольких команд и примерно $2 за генерации.

Отдельно можно пользоваться и кусками: сделать фото для сайта по своим снимкам, оживить
картинку, поправить готовую, нарезать своё видео на кадры.

Главное про деньги: **перед каждой генерацией видно цену, и без согласия ничего
не запускается.** Случайно потратить не получится.

Работает на macOS и Windows: обе системы проверяются автоматически при каждом изменении
кода. Из зависимостей только Node.js.

Что получается на выходе: [учебный лендинг](examples/landing/) целиком, с кадрами, фото
и сметой на 349 кредитов.

## Установка: четыре команды

Можно просто дать эту ссылку своему помощнику (Claude Code, Codex, Cursor) и сказать
«поставь и настрой». Он выполнит это сам:

```bash
npm i -g https://github.com/Killblonde/mgen.git
```

```bash
mgen setup
```

```bash
mgen skills install
```

```bash
mgen doctor
```

Первая ставит программу, вторая спрашивает ключ kie.ai, третья кладёт агенту инструкции
(как собирать лендинг и как делать для него графику), четвёртая проверяет, что всё на месте. Для других агентов вместо третьей команды:
`mgen skills install --for agents` (файл `AGENTS.md`, его понимают Codex, Cursor и другие),
`--for gemini` или `--for all`. Подробности ниже в разделах 4 и 8.

## 1. Что потребуется

**Node.js версии 18 или новее.** Если у вас стоит Claude Code — Node уже есть.
Проверить: откройте терминал и введите

```bash
node -v
```

Если видите номер версии (например `v22.15.0`) — всё в порядке. Если «команда не найдена»,
поставьте Node с сайта <https://nodejs.org> (кнопка LTS).

**Ключ kie.ai.** Это как пароль для программы: по нему сервис понимает, с чьего счёта
списывать деньги за генерации.

---

## 2. Ключ и деньги

1. Зарегистрируйтесь на <https://kie.ai>.
2. Пополните баланс (раздел Billing). Оплата — кредитами: **200 кредитов = $1**.
   Для начала хватит $5: это примерно 55 качественных картинок или 250 черновиков.
3. Откройте <https://kie.ai/api-key> и скопируйте ключ целиком.

Сколько стоит одна генерация:

| Что делаем | Сколько стоит |
|---|---|
| Черновик картинки (`--draft`) | 4 кредита ≈ $0.02 |
| Самый дешёвый набросок (`--model sketch`) | 0.8 кредита ≈ $0.004 |
| Качественная картинка (по умолчанию) | 18 кредитов ≈ $0.09 |
| Качественная картинка в 4K | 24 кредита ≈ $0.12 |
| Правка готовой картинки (`edit`) | 4 кредита ≈ $0.02 |
| Черновое видео 5 секунд (`video --draft`) | 19 кредитов ≈ $0.10 |
| Хорошее видео 5 секунд (`video`) | 140 кредитов ≈ $0.70 |

Полная таблица и как её обновлять — в [PRICES.md](PRICES.md).
Актуальные цены всегда на <https://kie.ai/pricing>.

## 3. Установка одной командой

```bash
npm i -g https://github.com/Killblonde/mgen.git
```

Проверить, что установилось:

```bash
mgen help
```

Если не хочется ставить насовсем, можно запускать так (команда сама скачает программу):

```bash
npx https://github.com/Killblonde/mgen.git help
```

Пока репозиторий лежит только на компьютере, установить можно из папки:

```bash
npm i -g ./mgen
```

---

## 4. Первый запуск: `mgen setup`

```bash
mgen setup
```

Программа попросит вставить ключ. **При вводе ключ не отображается** — это нормально,
просто вставьте и нажмите Enter. Дальше `mgen` сам проверит ключ и покажет баланс.

Ключ сохраняется в вашей домашней папке (`~/.mgen/config.json`, доступ только у вас).
В папку проекта он не попадает и на экран больше не выводится никогда.

Сколько осталось денег:

```bash
mgen balance
```

Какие есть модели и сколько стоят:

```bash
mgen models
```

Всё ли готово к работе (Node, ключ, баланс, ffmpeg, навыки):

```bash
mgen doctor
```

## 5. Пять примеров

### 5.1. Портрет по своим фото

Положите 3–5 своих фотографий в папку (лучше разные: лицо крупно, в полный рост,
разный свет и одежда). Затем:

```bash
mgen image "портрет в деловом стиле, светлый кабинет, мягкий свет от окна, взгляд в камеру, по грудь" --ref я1.jpg --ref я2.jpg --ref я3.jpg --size 4:5
```

Сходство будет хорошим, но не идеальным — это не фотошоп, а модель, которая «поняла»,
как вы выглядите. Больше хороших референсов — больше похожести.

### 5.2. Широкая картинка для шапки сайта

```bash
mgen image "первый экран сайта: ноутбук на деревянном столе у окна, утренний свет, тёплые цвета, слева свободное место под заголовок" --size 16:9
```

### 5.3. Три варианта картинки для сайта

Сначала дешёвые черновики, выбираете лучший:

```bash
mgen image "иллюстрация для раздела услуг: минимализм, две фигуры у большого экрана, спокойные синие тона" --draft --n 3 --size 16:9
```

Потом тот же промпт без `--draft` — получите финал в качестве:

```bash
mgen image "иллюстрация для раздела услуг: минимализм, две фигуры у большого экрана, спокойные синие тона" --size 16:9 --quality 2k
```

### 5.4. Оживить фото — сделать видео

```bash
mgen video portret.jpg "человек спокойно дышит, лёгкое движение волос, камера очень медленно приближается" --duration 5 --loop
```

`--loop` просит модель вернуть последний кадр к первому — такое видео можно зацикливать
на сайте, и шва почти не видно. Движение просите спокойное: резкие повороты модели даются плохо.

Дешёвая проба перед настоящим роликом:

```bash
mgen video portret.jpg "лёгкое движение волос, камера медленно приближается" --draft --duration 4
```

### 5.5. Правка готовой картинки

```bash
mgen edit cover.jpg "убери лишние предметы со стола, сделай фон темнее, оставь композицию как есть"
```

### 5.6. Видео с движением из точки А в точку Б

Если нужно, чтобы камера пришла в конкретный кадр, задайте начальную и конечную картинку:

```bash
mgen video start.jpg "камера медленно отъезжает назад, свет становится мягче" --end finish.jpg --res 720
```

`--res` принимает 480, 720 или 1080. Чем выше, тем дороже: пять секунд в 480p стоят
140 кредитов, в 720p уже 315. Цена всегда показывается до запуска.

### 5.7. Видео при прокрутке сайта

Это тот самый приём, когда страница листается, а в шапке идёт кино. Делается в три команды:

```bash
mgen video shapka.jpg "камера очень медленно приближается" --end finish.jpg --res 720
```

```bash
mgen frames generated/ваше-видео.mp4 --out ./site/frames --count 120
```

```bash
mgen template scroll --out ./site
```

Первая делает видео, вторая режет его на картинки, третья кладёт рядом готовые
`scroll-frames.js` и `scroll-frames.css`. Как вставить это в страницу, написано
в [templates/scroll/README.md](templates/scroll/README.md), там же лежит пример.

На телефоне и при включённом в системе «уменьшении движения» анимация не грузится:
показывается одна картинка. Так страница не съедает трафик и не раздражает тех,
кому движение мешает.

Сколько просить кадров, можно не думать: если попросите больше, чем есть в видео, `mgen`
возьмёт столько, сколько есть, и скажет об этом (пять секунд видео это 120 кадров). Ширину
он тоже не растягивает сверх исходной. В конце команда печатает готовое число для `data-count`.

Для нарезки кадров нужна программа **ffmpeg**. Если её нет, `mgen` сам предложит её поставить:
покажет, что и откуда скачает, сколько это весит, и спросит разрешение. Ставится она
в вашу домашнюю папку, права администратора не нужны, в систему ничего не прописывается.

### 5.8. Собрать сайт в один файл

Готовый сайт — это папка: index.html, стили, скрипт, фото и сотня кадров. Если унести
из неё один index.html, откроется голый текст без оформления. Чтобы показать сайт со сцены,
отправить в мессенджере или открыть на чужом ноутбуке без интернета, соберите его в один файл:

```bash
mgen pack ./site --out сайт.html
```

Внутрь одного HTML попадают стили, скрипты, фотографии, кадры прокрутки и шрифты Google
(они скачиваются и тоже кладутся внутрь, ссылка на fonts.googleapis.com убирается).
Внешних запросов у такого файла не остаётся ни одного: он открывается двойным щелчком
и работает в самолёте.

Кадры по умолчанию прорежаются до 90 — берутся равномерно по всей длине, первый и последний
на месте, а `data-count` в разметке пересчитывается сам. Иначе файл распухает, а движение
на глаз одинаковое. Флаги:

- `--out` куда положить готовый файл; по умолчанию это `<имя папки>.html`;
- `--frames 60` оставить меньше кадров, `--frames 0` — все до единого;
- `--max-mb 30` порог веса: если файл тяжелее, команда предупредит и спросит, писать ли его
  (по умолчанию 20 МБ, а `--yes` соглашается заранее — так это запускает агент);
- вес и число встроенных файлов команда печатает в конце.

Учебный лендинг из `examples/landing` (120 кадров шириной 1280, фото, два стиля, скрипт)
собирается в файл на 5.3 МБ: 90 кадров, 10 шрифтов, ноль внешних запросов.

Исходную папку команда не трогает: её по-прежнему можно править и выкладывать на хостинг.
Один файл — это копия для показа, а не замена сайту.

## 6. Куда попадают файлы

В папку `generated/` там, откуда вы запустили команду:

```
generated/
  2026-10-22_1540_portret-v-delovom-stile.jpg
  2026-10-22_1540_portret-v-delovom-stile.json
```

Рядом с каждым файлом лежит `.json` — в нём промпт, модель, параметры, цена и номер задачи.
Удобно, когда через месяц хочется повторить удачную картинку.

Хотите в другую папку — добавьте `--out ./covers`.

## 7. Если видео делается долго

Видео может считаться несколько минут — это нормально, программа ждёт и показывает время.
Если вы прервали ожидание, задача не потерялась: `mgen` печатает её номер, и результат
можно забрать позже:

```bash
mgen status dc1928bfcbc77cb6c85f3359a9c718b3
```

Готовый файл скачается в `generated/`.

## 8. Подключить навыки к агенту

Чтобы не помнить флаги, попросите помощника словами: «собери лендинг по этому скриншоту»,
«сделай фото для первого экрана», «оживи эту картинку» — он сам соберёт команду и покажет цену.

Навыков два: `mgen` (картинки и видео) и `mgen-site` (сборка лендинга по скриншоту-референсу,
с видео при прокрутке). Ставятся одной командой, пути искать не нужно:

```bash
mgen skills install
```

Команда кладёт оба навыка в `~/.claude/skills/` и работает одинаково на macOS и Windows.
Посмотреть, что установлено:

```bash
mgen skills
```

### Другие агенты: Codex, Cursor, Gemini

Формат навыков понимает только Claude Code, но сам `mgen` это обычная команда терминала,
и пользоваться им может любой агент. Те же правила выгружаются привычным для него файлом
**в папку вашего проекта**:

```bash
mgen skills install --for agents
```

Это создаст `AGENTS.md` — общий формат, который читают Codex, Cursor и ещё десятки
инструментов. Для Gemini CLI нужен свой файл: `--for gemini` положит `GEMINI.md`.
Для правил Cursor: `--for cursor` (`.cursor/rules/mgen.mdc`). Всё сразу: `--for all`.

Внутри этих файлов то же самое, что в навыках: когда звать `mgen`, как писать промпт,
правило «сначала черновики, потом финал» и обязательный показ цены до траты денег.

После этого перезапустите Claude Code. Проверить: пришлите ему скриншот понравившегося сайта
и попросите «сделай похожий лендинг» — включится навык `mgen-site`: он разберёт стиль словами,
покажет макет с переключателями шрифтов и палитр и доведёт до готовой страницы с видео при
прокрутке. А на просьбу «сгенерируй картинку кота в скафандре» сработает навык `mgen`:
предложит команду и покажет цену.

## 9. Частые вопросы

**«Не вижу ключа kie.ai».** Запустите `mgen setup`. Или задайте переменную окружения
`KIE_API_KEY` — она важнее сохранённого файла.

**«Не хватает кредитов».** Программа скажет, сколько есть и сколько нужно. Пополните баланс
на kie.ai или возьмите вариант дешевле: `--draft`.

**«Файл не найден».** Проверьте путь к фото. Проще всего перетащить файл в окно терминала —
путь подставится сам.

**«kie.ai просит сбавить темп».** Сервис разрешает 20 новых генераций за 10 секунд.
`mgen` сам подождёт и повторит.

**Как узнать, какие есть флаги у команды?** Допишите `--help`: `mgen video --help` покажет
пример и список флагов с пояснениями.

**Можно ли запускать без вопросов?** Да, флаг `--yes` пропускает подтверждение. Так работает
Claude Code, когда вы уже согласились с ценой.

**Есть примеры того, что получается?** Да, папка [examples/](examples/) — там картинка-черновик,
картинка по двум референсам и видео с петлёй, у каждой рядом JSON с промптом и ценой.

**Где посмотреть историю генераций?** На <https://kie.ai/logs> — там все задачи, параметры
и списания. Готовые файлы kie.ai хранит 14 дней, поэтому `mgen` сразу скачивает их к вам.
